## At a glance

| Aspect | Rule |
|---|---|
| Teams | 2–6 teams, 2+ players each |
| Words | Each player adds words to a shared hat (default 10 per player) |
| Rounds | 3 — the same words, with a stricter explaining rule each round |
| Turn length | Timed (default 60 seconds), one team at a time |
| Scoring | 1 point for every word guessed |
| Winner | The team with the most total points after Round 3 |
| Modes | Pass-and-play (one device), Online, Nearby |

The rules of play — the hat, the three rounds, turns, and scoring — are identical in every mode. Only how players are gathered and how words are collected differ. See [Play Modes](play-modes.md).
